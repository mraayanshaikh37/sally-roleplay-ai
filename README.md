# 💛 Sally -- AI Emotional Companion

> Every intelligent companion starts with a conversation.

Sally is a browser-based AI companion designed to provide natural conversations, emotional support, and multimodal interactions through a modern chat interface.

Unlike a traditional chatbot, Sally focuses on realistic communication while supporting image understanding, persistent memory, and future document analysis capabilities.

---

# 📖 About

Sally is an experimental AI companion created to explore conversational AI, multimodal interaction, and user-centered interface design.

The project combines modern browser technologies with AI models to create an experience that feels closer to chatting with a real companion than using a traditional chatbot.

Sally continues to evolve with new features focused on richer interactions and improved usability.

# ⚙ Working Principle

1. User sends a message or image.
2. Sally stores conversation history locally.
3. Messages are sent to the AI model.
4. If an image is attached, the vision model analyzes it.
5. Sally generates a contextual response.
6. Conversation history is updated automatically.
